04 · SSH ACCESS

用 SOCKS5 走 SSH

SOCKS5 落地由你自己建，凭据只在个人中心里，不出现在这一页。

怎么建

在「我的自定义节点」里加一条 SOCKS5 落地

填服务器、端口、用户名口令，再选一个前置节点—— 连到那台 SOCKS5 服务器的这条连接本身就从前置拨出去。

前置选了受管入口，这条流量照常计费

它整条都经过我们的节点，照常计入用量、照常受额度约束。 前置是 DIRECT 或你自己的自定义上游时才不计费。

打开我的自定义节点 登录后配置

~/.ssh/config

把它挂到一条 SSH 别名上

需要本机装 Ncat。把尖括号里的四处换成自己的值，之后 ssh target-via-proxy 就走这条落地。 

Host target-via-proxy
  HostName <目标服务器>
  User <SSH用户名>
  ProxyCommand ncat --proxy <SOCKS服务器>:<端口> \
    --proxy-type socks5 --proxy-auth <用户名>:<密码> %h %p

这条链路只有 TCP CONNECT，没有 UDP。
