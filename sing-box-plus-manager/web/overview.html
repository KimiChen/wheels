P1 · 额度结果不明（节点 node-c）

下发无可信响应，不能证明旧授权已失效。恢复流程先核对 runtime， 再以更高 epoch 的表收敛；本轮照常重算，代价是可能重复授信（D20、§10 R2）。

P2 · 节点时钟偏移（节点 node-f）

采集时刻与主控收到时刻相差 41s，已回落按收到时刻归桶并标 time_quality = fallback。请检查该节点的 NTP（C27）。

P2 · 身份数逼近上限（节点 node-a）

已配置 892 / 1024。再加身份会撞 C29——而越界是通过 SIGHUP 发生的话， 不可入账位会粘滞到该 runtime 结束。请安排排空窗口扩容。
