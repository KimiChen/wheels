主控绑回环，对外域名由反代决定；回调地址要拼得出来， 会话 cookie 带 __Host- 前缀因而必须走 HTTPS。 任一项没落实，登录都会以「登录成功但立刻又没登录」的形式失败。

本地应急管理员

默认禁用。存在的理由很具体：上游 SSO 一旦因回调域名、出口 IP 或 对端故障而不可用，登录会整体失效，那时不能把所有人锁在门外。 启用需改配置文件，登录后强制二次确认。

注意它与其他人的区别：本地应急管理员的角色取自数据库， 不走成员名单——名单那条路走不通正是它存在的场景。

当前已禁用
