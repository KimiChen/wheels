    节点接入

    1. 创建节点，保存只显示一次的节点令牌。
    2. 在 agent 的 telemetry 配置中填写主控 WSS 上报地址、serverID 和私有令牌文件路径。
    3. 配置受信任证书并启动 agent，在节点列表确认接入状态。

    接入令牌仅用于监控上报。令牌丢失时，可在节点编辑窗口的「接入凭据」中轮换。
